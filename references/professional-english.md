# Integrated Professional English

Use this reference for Scan, Review, Reading Note, and Solve whenever the source or problem contains electrical-engineering English. The goal is familiarity with language that unlocks the current technical content, not a detached general-English vocabulary list.

## Learning outcome

Help the learner gradually:

- recognize an English term and understand the corresponding technical concept;
- recall the usual English expression from the Chinese concept;
- notice English trigger phrases that determine a model, formula, constraint, or reasoning path;
- connect English labels with formulas, diagrams, units, and physical meaning;
- distinguish nearby expressions whose everyday meanings or technical scopes differ.

## Selection and provenance

- Select only high-value terms, intact technical phrases, recurring collocations, problem triggers, diagram labels, and context-specific confusions that directly support the current lesson.
- Preserve meaningful phrases such as *mathematical modeling*, *input-output relationship*, *zero initial conditions*, *transfer function*, *mass-spring-damper system*, and *steady-state response*. Do not fragment them into isolated words that lose their technical meaning.
- Do not impose a fixed count. Ordinary words and decorative slide text should be omitted.
- Record the physical PDF page and verified printed page for every selected expression. Write “未核实” rather than guessing a printed page.
- Source wording and page evidence must come from the current source or approved Canonical evidence. Mark usage notes or distinctions added by Codex as supplemental explanation.
- Translate according to the active electrical-engineering or control context. If a term has several technical senses, explain only the current one and state the scope.
- Pronunciation is optional. Add it only when reliable and useful for a commonly misread term, or when the user asks.

## Integrated presentation

At the first important occurrence—in the heading or first explanatory sentence—use `中文名称（English term）` or `English term（中文名称）`; do not postpone the bilingual name until a later vocabulary list. Avoid repeating both languages every time.

Apply [Teaching Foundations](teaching-foundations.md) in the body: establish what the concept means, which source object/label it refers to and why it is used. Translation into another unfamiliar term is insufficient. State/condition phrases must connect to their justified mathematical constraint and its consequence. Preserve intact source phrases; mark authored English absent from the page as supplemental expression. Repeating a term from an earlier page still requires the recap needed for the current reasoning.

During Scan/Review and in unsectioned material, add a compact “专业英语” block after the relevant page or knowledge topic. In new paired page-by-page notes, bind selected expressions to the original region and first-use knowledge point, and explain them inside its nearby technical teaching. Do not render an independent vocabulary box for a lone term. Source phrases, Chinese meaning and source object must be identifiable in the same teaching unit. The historical sequential layout retains its page-bound vocabulary phase for compatibility. Already-explained terms need not be relisted every page. Legacy section notes retain **本节生词** after **本节课件** and before **正文讲解**; keep the first important concept bilingual in the body in either mode. Each entry should include:

- the English term or phrase;
- the Chinese meaning in the current context;
- its technical role on that page;
- a useful collocation or problem wording when supported;
- source page;
- a confusion note only when it materially prevents misunderstanding.

Present English normally or in italics. Never format terms, formulas, variables, or example expressions as program code.

## Batch review and recall

When a consolidated review has real teaching value, end a learning batch with a deduplicated “本批专业英语回顾” in knowledge order rather than alphabetical order. Each retained expression should answer:

1. What does it mean here?
2. Which concept, formula, diagram, or physical meaning does it connect to?
3. On which page does it appear?
4. What should it trigger when seen in an English problem?

When worthwhile, add a small set of active-recall prompts: English to Chinese concept, Chinese to English expression, phrase completion, and trigger-to-model/formula selection. Put the answer key under its own heading or in a visually distinct block after all questions; never place answers in the same paragraph or immediately after each prompt.

## Candidate and Canonical boundary

Each user-readable candidate card should include “关联英语表达” with only the terms needed to understand or retrieve that candidate, and with source pages.

Do not create a standalone Canonical object for each word or phrase. Ordinary vocabulary stays in rendered Review and Reading Note presentation. Propose formal retention only when a term carries a concept boundary, common technical misunderstanding, retrieval alias, or problem-solving Trigger. In that case it may become part of a Concept English title/alias, Problem Trigger, Formula or Diagram search term, or Insight distinction, and still requires the existing exact-version Review and explicit user approval.

## Reading Note

Provide a stable professional-English section containing core terms, collocations, English problem triggers, useful distinctions, and bidirectional recall prompts. Derive it only from the Canonical object and verified sources; do not change Canonical meaning.

Professional-English presentation remains in the Reading Layer and outside knowledge Search and Relations unless a particular alias or Trigger has been separately reviewed and approved. Preserve vocabulary familiarity, memory cues, and personal notes inside `USER-NOTES-START` and `USER-NOTES-END` exactly.

## Solving English or bilingual problems

- Extract and explain only the English phrases that influence method selection.
- Give the bilingual name at the first occurrence of a core concept.
- Explain why a phrase points to a model, formula, boundary condition, or constraint.
- Keep vocabulary notes subordinate to the reasoning chain; do not mechanically translate the whole solution.
- At the end, optionally list “本题需要认识的英文表达” when those expressions materially affected understanding or method choice.

## User-facing delivery

Follow [User-Facing Delivery](user-delivery.md). English, Chinese, formulas, and images must be rendered together in readable conversation content or a fully typeset PDF/HTML artifact. Never make the user inspect the internal Markdown vocabulary record.
