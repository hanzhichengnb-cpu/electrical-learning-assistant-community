# Personal reading annotations

Use the workspace's local reader and fine-annotation contracts. Page stars/notes and fine annotations are separate personal records, not Canonical knowledge, approvals or study progress. Personal UI actions create no learning checkpoints or saving suggestions.

For maintenance, preserve published bytes and private data; use isolated stores for interaction acceptance. Text anchors require exact quotations and reliable unique content locations. Image/MathJax rectangles bind object evidence and relative coordinates. Never fuzzy-match changed prose, guess formula text, fabricate Source pages or transfer positions across PDF versions. Retain orphan evidence/notes and show needs-check status; label legacy provenance limits.

In the original reader, saved personal remarks are readable by default after the text range's ending paragraph or the image/formula's containing block. Matching visible numbers plus quotes/crops distinguish multiple marks. Edit and save in place; collapse is a user choice, and highlight-only records have a compact add-remark entry. My Annotations assists cross-note review. Existing records need no migration. Unlocated remarks remain readable with original evidence and explicit needs-check status, without an invented corresponding mark.

Runtime remark cards, numbers and tools must be excluded from text indexing, ranges and source-object recognition. Exclude explicitly marked UI subtrees, not a reading-mode class on the body. Keep focused editor nodes, input and caret during refresh, and recalculate object-relative overlays after flow changes. Across regenerated artifacts, regions require both object evidence and surviving exact local context; a sole surviving duplicate is not sufficient proof.

Follow atomic writes, backups, optimistic per-record revisions, merge import/export and session/Origin protection. Preserve failed input; never reset corrupt personal files or silently overwrite conflicts. Test selection/copy, desktop keys, native textarea undo, review jumps, reflow/zoom, restart and update isolation. Local tab concurrency does not imply multi-device cloud support.
