# Extract

Use after the user selects a concrete candidate or source region.

1. Confirm the selected candidate, source version, physical page, verified printed page and extraction kind.
2. Reuse an existing approved Capture when it already contains the needed evidence. Otherwise use the workspace PDF crop CLI with an explicit normalized bbox and expected source hash.
3. Visually inspect the result for complete axes, legends, bars, subscripts, gate bubbles, equations and labels. Re-crop within the approved target when necessary.
4. Prepare Explanation and supported object drafts in Staging. Distinguish source evidence from Codex explanation.
5. Share one Capture across multiple objects when appropriate; never copy it solely to create another Relation. When showing a Capture to the user, embed the image with a human caption under [User-Facing Delivery](../references/user-delivery.md); a path or Markdown link is not a review artifact.
6. Checkpoint the fixed source/capture references and move to Review. Do not publish.
