# Solve

Use when the user solves a new problem with an active Electrical Engineering Learning System workspace.

1. Resume relevant state without assuming the old conversation is available.
2. Extract Problem Structure, knowns/unknowns, constraints, visual features and Trigger phrases. For an English or bilingual problem, apply [Integrated Professional English](../references/professional-english.md): identify the English expressions that actually determine the model, formula, boundary condition or constraint, and record how they guide method selection.
3. Detect Course Recall capability: both `00_System/specs/course-recall-v1.2.md` and `tools/recall.py` must exist in the workspace. When available, read the local specification, search Course Recall and Canonical Search separately, and merge/deduplicate by topic and source while preserving authority labels. When unavailable, say that retrieval is using the compatible Canonical-only path and do not call Course Recall.
4. Present matches in three confidence layers when Course Recall is available: approved Canonical knowledge, current relevant course content, and possible/stale matches. Reading-derived and source-derived text are locators, not approved facts. Even if Canonical has no match, current course pages may still locate the relevant lesson.
5. Prefer a close prior Problem or other high-confidence Canonical object when returned and traverse its Relations to exact Concept, Formula, Diagram, Data, Insight and related Problem objects. Open only a few necessary Reading fragments and original source pages; verify formulas, subscripts, diagrams, reference directions and conditions before teaching.
6. Apply [Teaching Foundations](../references/teaching-foundations.md): establish required concepts before inference, justify conditions and method choice, and locally recap dependencies. Explain the reasoning chain, units, assumptions, checks and engineering meaning under [User-Facing Delivery](../references/user-delivery.md). On first use, give the bilingual name of each core concept and explain why decisive English phrases point to the chosen method. Render formulas and embed any needed diagrams; do not mechanically translate the whole solution or let vocabulary interrupt the reasoning chain. Distinguish retrieved knowledge from new derivation.
7. When useful, end with a concise “本题需要认识的英文表达” containing only terms that affected understanding or method choice.
8. During ordinary solving, keep any possible long-term insight in this conversation. Ask about saving only when a real solution has clear value beyond the current problem, and ask at most once using exactly 保存、修改后保存、暂不保存、不再建议. Do not create a Candidate, Review, Knowledge Pack file or pending state before 保存 or 修改后保存; either non-save choice ends cleanly. A save choice starts [Review](review.md), while exact-version Canonical publication still needs its own approval. Implementation reports, feature acceptance and routine note completion do not ask this question.
9. Checkpoint active problem state only when work must continue across sessions.

Reading Notes and Course Recall improve location and recall; original Sources and approved Canonical objects establish final reliability.
