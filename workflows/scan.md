# Scan

Use for “扫描这些页” or Focus Mode in the active learning workspace.

1. Resume state first when an active session exists. Resolve the Source through its registry and verify the requested physical/printed page convention.
2. Read/render only the requested pages. Text extraction is a locator; visually verify equations, bars, subscripts, diagrams and page numbers.
3. Search concise terms/triggers to detect existing Canonical coverage. Do not read the entire knowledge base.
4. In the same page pass, apply [Integrated Professional English](../references/professional-english.md): identify only source-grounded core terms, intact technical phrases, problem triggers, diagram/formula labels and materially confusing expressions; record their physical and verified printed pages. Do not set a quota or collect ordinary words.
   Apply [Teaching Foundations](../references/teaching-foundations.md) to explanations: establish concepts before inference and explain how source conditions become mathematical constraints. Supplementary teaching also needs explanation and attribution.
5. Keep potential long-term knowledge as session-local, non-blocking suggestions. Do not create `candidates.md`, a persistent Candidate, or global pending state by default.
6. In Focus Mode, continue through the requested material. Interrupt only for a missing prerequisite, a source/meaning error that affects current understanding, an explicit request for immediate discussion, or a user request to prepare one suggestion for saving.
7. Checkpoint source/page progress. Create and checkpoint a persistent Candidate only after the user explicitly asks to save the item or chooses 保存/修改后保存 on a concrete Knowledge Pack.

Present scan results under [User-Facing Delivery](../references/user-delivery.md): render a concise learning summary in the conversation, or generate a complete PDF when the batch is long or image-heavy. Embed the relevant page evidence, integrate selected English expressions after their page/topic, and end with a deduplicated professional-English review in knowledge order. Suggestions do not require cleanup or a decision. If the user asks to save one, route it through [Review](review.md) and show a human-readable card rather than an internal file.

If Scan produces a source-range study note, follow [Reading Note](reading-note.md) and the workspace page-study specification. The note's quality and publication rules are defined there.

Do not crop or publish merely because a session-local suggestion looks valuable.
