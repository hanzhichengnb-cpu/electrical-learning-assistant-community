# 课件笔记 · 独立分享版

版本：0.1.0 试用版。首版聚焦 PDF 课件。

- 分享给 AI 的入口：https://github.com/hanzhichengnb-cpu/electrical-learning-assistant-community/tree/standalone-share-v0.1.0-preview
- 完整包下载：https://github.com/hanzhichengnb-cpu/electrical-learning-assistant-community/archive/refs/heads/standalone-share-v0.1.0-preview.zip

把课件 PDF 发给能操作文件的 AI Agent，让它自动整理成可离线打开的交互笔记。

**给使用者的操作只有两步：把这个包交给 AI，再把自己的课件发给它。** 建目录、准备环境、读取原页、写讲解、排版公式、整理笔记和更新首页，按 Skill 交给 AI 完成。

给 AI 的一句话：

> 读取这个包中的 SKILL.md，使用课件笔记分享版。根据我上传的课件生成完整讲解，自动完成准备和整理，最后给我可以打开的笔记网页。

## 阅读体验

- 桌面端左侧看原课件，右侧看对应讲解；点击原页中的编号或框内定位知识点。
- 右侧讲解独立滚动；鼠标放在左侧滚动时切换页面。手机端自动上下排列。
- 公式离线排版，原页可以放大，笔记可以打印。
- 所有课程汇入可搜索的首页，修改笔记时保留旧版本。
- 每份笔记是一个独立 HTML 文件，拷走后仍能阅读；打开 index.html 即可进入笔记库。

它自带建库、PDF 预处理、网页渲染、复核和版本整理工具，**不要求使用者预先拥有作者的学习工作区**。原始课件、个人笔记和状态不会混入可分享的 Skill 包。

## “任何 AI”需要哪些条件

不绑定模型品牌，但 Agent 的实际环境需要：

| 能力 | 用途 |
|---|---|
| 读取附件、读写文件 | 接收课件并保存笔记 |
| 查看 PDF 页图像 | 理解公式、图表、电路和扫描内容 |
| 执行 Python 3.10+ | 自动准备原页、整理和生成网页 |
| 使用现有 PDF 依赖，或允许下载依赖 | 首次准备环境；已有环境无需重复安装 |
| 查看网页/浏览器效果 | 检查真实点选、滚动、公式和版式 |
| 打开或交付生成的 HTML | 把结果交到使用者手上 |

仅有对话功能或只有联网搜索功能的 AI 无法保证这套体验。依赖下载、程序执行、文件持久保存和本机网页打开权限由具体平台决定；Skill 不会绕过这些限制。在临时云端环境中，AI 应交付可下载的 HTML/笔记库压缩包。

首次设置可能需要下载 Python PDF 依赖。生成的阅读页自身不依赖网络或常驻服务器。Mac/Windows 打开辅助文件可能受系统安全提示限制，始终可以直接用浏览器打开 index.html。

## 范围与验证

当前版本聚焦“PDF 课件 → 源页关联讲解 → 离线网页笔记”。自测、批改和复杂个人批注不在这一版入口中，避免把首次使用重新变成系统配置工作。

代码和网页在本机真实课件上进行测试；这不等于已经在每一家 Agent 平台上实测。包中的程序只做确定性处理，教学由使用者正在运行的 AI 完成，不调用外部模型 API，也不保证不同模型会生成相同质量的讲解。

## 包内容

- SKILL.md：AI 的入口。
- references/：自动工作流程、教学要求、笔记与复核格式。
- scripts/：独立环境设置、课件处理、渲染、版本管理和可选浏览器检查。
- assets/：离线阅读器和公式排版。

只需分享本目录或其压缩包。不要把使用后生成的 Course Notes 文件夹一起作为通用 Skill 再分发，其中会含使用者自己的课件与笔记。

## 第三方组件

MathJax 3.2.2 的预构建 SVG 公式引擎随包提供，许可证及来源见 THIRD_PARTY.md。PDF 渲染只额外依赖 pypdfium2，由隔离环境按需安装，不在包内附带其二进制程序。
